# Sales

The **Sales** tab displays the referral sales recorded using affiliate referrals. When a customer purchases using an affiliate's referral link or coupon, that sale is recorded in the Sales tab.

<figure><img src="../../../.gitbook/assets/image (3956).png" alt=""><figcaption><p>Sales</p></figcaption></figure>

### Sales

In the **Sales** section, you can view all the sales recorded using affiliate referrals. Here, you can filter sales by affiliate name, status, order number, order type, and date. The summary table displays the total sales, revenue, and commission earned.&#x20;

The table displays statistics like the order date, order number, amount, affiliate name, commission, and status. You can also download a sales report with this order data.

<figure><img src="../../../.gitbook/assets/image (3957).png" alt=""><figcaption><p>Sales</p></figcaption></figure>

### Assign sale to affiliate

You also have the option to manually **assign a sale** to an affiliate by using the create a new sale manually feature. Here you can select the order number and affiliate name to assign the order.&#x20;

![Assign Sale to Affiliate](<../../../.gitbook/assets/image (1975).png>)

#### Create a new sale

Additionally, you can **create a new sale** and assign it to the affiliate. Here, you can create a new order by selecting the affiliate, setting the order number, date, and affiliate commission. You can also set the customer name, email, order line items (products), quantity, and price.&#x20;

![Create a new sale](<../../../.gitbook/assets/image (1475).png>)

### Bulk Import Orders

You can also import orders into your program. In the **Bulk Import Orders** section, you can import up to 200 orders in a single batch by uploading a formatted CSV file.&#x20;

{% hint style="info" %}
To make sure the CSV file you upload is correctly formatted, you can download &#x74;_&#x68;_&#x65; sample CSV file and use it to create your bulk import file. There is also a glossary of headings to help you understand the terms used in the sample CSV file.
{% endhint %}
