# Customize Sales Table

**GoAffPro** provides you with the option to customize the Sales table.

{% hint style="info" %}
You can customize the Sales table to display additional sale information such as the coupon used, conversion source, etc.&#x20;
{% endhint %}

To customize the Sales table, go to the **Sales** tab in the GoAffPro admin panel.

<figure><img src="../../../.gitbook/assets/image.png" alt=""><figcaption><p>Sales</p></figcaption></figure>

Here, click on **Settings**.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-09-16 232859.png" alt=""><figcaption><p>Click on Settings</p></figcaption></figure>

This will open up the Show Columns window.

<figure><img src="../../../.gitbook/assets/image (3958).png" alt=""><figcaption><p>Show Columns</p></figcaption></figure>

Here, select the column that you want to add to the table.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-09-16 233206.png" alt=""><figcaption><p>Select the column</p></figcaption></figure>

Now, click on **Save**.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-09-16 233221.png" alt=""><figcaption><p>Click on Save</p></figcaption></figure>

After this, the column will get added to the Sales table.

<figure><img src="../../../.gitbook/assets/image (3960).png" alt=""><figcaption></figcaption></figure>
