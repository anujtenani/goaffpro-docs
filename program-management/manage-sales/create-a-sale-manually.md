# Create a Sale Manually

**GoAffPro** provides you with the option to manually create new sales for affiliates. &#x20;

To create a sale manually, go to the **Sales** tab in the GoAffPro admin panel.

<figure><img src="../../.gitbook/assets/image (3966).png" alt=""><figcaption><p>Sales</p></figcaption></figure>

Here, click on **create a new sale manually**.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-01 130847 (1).png" alt=""><figcaption><p>Click on create a new sale manually</p></figcaption></figure>

This will open up the **Assign Sale to Affiliate** section.

<figure><img src="../../.gitbook/assets/image (3970).png" alt=""><figcaption><p>Assign Sale to Affiliate section</p></figcaption></figure>

Now, click on **Manually create an order.**

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-01 13085012.png" alt=""><figcaption><p>Click on Manually create an order</p></figcaption></figure>

This will open up the **Manually Create a new sale** sectio&#x6E;**.**

<figure><img src="../../.gitbook/assets/image (3971).png" alt=""><figcaption><p>Manually create a new sale</p></figcaption></figure>

Here, select the affiliate (to whom you want to assign the sale), fill in the order number, select the date and time of the order, and set the affiliate commission.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-01 132141.png" alt=""><figcaption><p>Set order details</p></figcaption></figure>

You also have the option to set the customer name and email.&#x20;

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-01 132145.png" alt=""><figcaption><p>Set customer name &#x26; email</p></figcaption></figure>

There is also the option the add product details, such as the product name, quantity, and price.

{% hint style="info" %}
To add details of additional products, click on **Add line item**.
{% endhint %}

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-01 132152.png" alt=""><figcaption><p>Add product details</p></figcaption></figure>

Next, you can set the order status.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-01 132156421.png" alt=""><figcaption><p>Set order status</p></figcaption></figure>

After this, click on **Submit**.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-01 13215642.png" alt=""><figcaption><p>Click on Submit</p></figcaption></figure>

The newly created sale will appear in the Sales tab.

<figure><img src="../../.gitbook/assets/image (3972).png" alt=""><figcaption></figcaption></figure>
