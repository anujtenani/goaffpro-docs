# Set Affiliate's Withholding Tax Rate

**GoAffPro** provides you with the option to set an affiliate's withholding tax rate.&#x20;

To set an affiliate's withholding tax rate, go to the **All Affiliates** section in the **Affiliates** tab of the GoAffPro admin panel.

<figure><img src="../../../.gitbook/assets/image (3962).png" alt=""><figcaption><p>Affiliates > All Affiliates</p></figcaption></figure>

Here, click on the **affiliate's name**.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-09-24 011208.png" alt=""><figcaption><p>Click on the affiliate's name</p></figcaption></figure>

This will open up the affiliate's profile.

<figure><img src="../../../.gitbook/assets/image (3964).png" alt=""><figcaption><p>Affiliate Profile</p></figcaption></figure>

Now, go to the **Settings** tab.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-09-24 011215.png" alt=""><figcaption><p>Settings tab</p></figcaption></figure>

Here, go to the Tax ID section.

<figure><img src="../../../.gitbook/assets/image (3965).png" alt=""><figcaption><p>Tax ID</p></figcaption></figure>

Next, click on the **edit** icon.&#x20;

<figure><img src="../../../.gitbook/assets/Screenshot 2026-09-24 011219.png" alt=""><figcaption><p>Click on the edit icon</p></figcaption></figure>

After this, set the withholding tax rate.&#x20;

<figure><img src="../../../.gitbook/assets/Screenshot 2026-09-24 011252.png" alt=""><figcaption><p>Set the tax rate</p></figcaption></figure>

Finally, click on **Submit**.&#x20;

<figure><img src="../../../.gitbook/assets/Screenshot 2026-09-24 0112562.png" alt=""><figcaption><p>Click on Submit</p></figcaption></figure>

The withholding tax rate will be set for the affiliate.

<figure><img src="../../../.gitbook/assets/image (3963).png" alt=""><figcaption></figcaption></figure>
