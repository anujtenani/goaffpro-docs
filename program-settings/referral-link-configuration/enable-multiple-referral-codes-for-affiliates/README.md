# Enable Multiple Referral Codes for Affiliates

**GoAffPro** provides you with the option to allow affiliates to have multiple referral codes.&#x20;

{% hint style="info" %}
With the multiple referral codes feature, affiliates can create and manage multiple unique referral codes for their referral links. This functionality enables them to generate several distinct referral links and integrate them into their promotional activities.
{% endhint %}

To allow affiliates to have multiple referral codes, go to the **Advanced** section of the **Settings** tab in the GoAffPro admin panel.

<figure><img src="../../../.gitbook/assets/image (3415).png" alt=""><figcaption><p>Settings > Advanced</p></figcaption></figure>

Now, go to the Referral link section.

<figure><img src="../../../.gitbook/assets/image (3416).png" alt=""><figcaption><p>Referral link</p></figcaption></figure>

Here, in the Multiple Referral Codes option, enable the toggle.

<figure><img src="../../../.gitbook/assets/Screenshot 2024-01-23 115040 (2).png" alt=""><figcaption><p>Enable the toggle</p></figcaption></figure>

After this, affiliates will be able to have multiple referral codes.

{% hint style="info" %}
This option allows affiliates to have up to 10 referral codes.&#x20;
{% endhint %}

<figure><img src="../../../.gitbook/assets/image (3420).png" alt=""><figcaption></figcaption></figure>

<details>

<summary>Setup Multiple Referral Codes</summary>

#### To set up multiple referral codes for affiliates as a merchant:

Go to the affiliate's profile settings.

<figure><img src="../../../.gitbook/assets/image (3997).png" alt=""><figcaption><p>Affiliates > All Affiliates > Click on the Affiliate's name > Settings</p></figcaption></figure>

In the Referral Code section, the referral codes for the affiliate (one referral code per line).

<figure><img src="../../../.gitbook/assets/image (3998).png" alt=""><figcaption><p>Enter the referral codes</p></figcaption></figure>

Now, click on **Submit**.

<figure><img src="../../../.gitbook/assets/image (3999).png" alt=""><figcaption><p>Click on Submit</p></figcaption></figure>

{% embed url="https://youtu.be/Rwit2cT1h6Y?si=LCSP_mZbhnRR_JwX" %}

#### To set up multiple referral codes as an affiliate:

Go to the **Settings** section in the affiliate dashboard.

<figure><img src="../../../.gitbook/assets/image (4000).png" alt=""><figcaption><p>Affiliate Dashboard > Settings</p></figcaption></figure>

Here, click on **Change** in the Referral Code section.

<figure><img src="../../../.gitbook/assets/image (4001).png" alt=""><figcaption><p>Click on Change</p></figcaption></figure>

After this, enter the referral codes (one referral code per line).

<figure><img src="../../../.gitbook/assets/image (4002).png" alt=""><figcaption><p>Enter the referral codes</p></figcaption></figure>

Finally, click on **Save Changes**.

<figure><img src="../../../.gitbook/assets/image (4003).png" alt=""><figcaption><p>Click on Save Changes</p></figcaption></figure>
