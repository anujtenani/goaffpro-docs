# Secure Manager Access

**GoAffPro** provides you with the option to secure admin panel access for users with manager accounts.&#x20;

To secure admin panel access for users with manager accounts, go to the **Extras** section in the **Settings** tab of the GoAffPro admin panel.

<figure><img src="../../.gitbook/assets/image (3908).png" alt=""><figcaption><p>Settings > Extras</p></figcaption></figure>

Here, go to the Manager accounts section.&#x20;

<figure><img src="../../.gitbook/assets/image (3909).png" alt=""><figcaption><p>Manager accounts</p></figcaption></figure>

Now, click on **New Manager Account**.&#x20;

<figure><img src="../../.gitbook/assets/Screenshot 2026-07-06 173218.png" alt=""><figcaption><p>Click on New Manager Account</p></figcaption></figure>

Next, enter the manager's name and email address.

<figure><img src="../../.gitbook/assets/Screenshot 2026-07-06 173316.png" alt=""><figcaption><p>Enter the manager's name and email address</p></figcaption></figure>

After this, click on **Submit**. The manager account will be created.

<figure><img src="../../.gitbook/assets/Screenshot 2026-07-06 173221.png" alt=""><figcaption><p>Click on Submit</p></figcaption></figure>

Now, go to the Manager only access section and enable the **toggle**.&#x20;

<figure><img src="../../.gitbook/assets/Screenshot 2026-07-06 1732262.png" alt=""><figcaption><p>Manager only access > Enable the toggle</p></figcaption></figure>

This will disable direct app access through the Shopify admin panel. Only users with manager accounts will be able to access the admin panel via goaffpro.com/login&#x20;

<figure><img src="../../.gitbook/assets/image (3911).png" alt=""><figcaption></figcaption></figure>

<summary>FAQ</summary>

**Why should I secure the admin panel access to manager accounts?**

If your team has access to your Shopify admin panel (with broad app access), those users can access GoAffPro and make changes. To safeguard against unauthorized access, you can enable the "Manager Only Access" feature. ​

This will prevent users with access to the Shopify admin panel from accessing the GoAffPro app. Only users with manager accounts can access the app's admin panel.

**What would users see when accessing GoAffPro through the Shopify admin panel if the "manager only access" feature is activated?​**

Users will see a message upon opening the GoAffPro app, indicating that direct access has been disabled. They can access GoAffPro through goaffpro.com/login using their manager account.
