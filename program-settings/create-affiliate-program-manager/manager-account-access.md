# Limit Access to Manager Accounts

**GoAffPro** provides you with the option to limit access to the admin panel for manager accounts.

To limit access to the admin panel for manager accounts, go to the **Extras** section in the **Settings** tab of the GoAffPro admin panel.

<figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption><p>Settings > Extras</p></figcaption></figure>

Here, go to the Manager accounts section.

<figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption><p>Manager accounts</p></figcaption></figure>

Now, click on **New Manager Account**.

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-25 205702.png" alt=""><figcaption><p>Click on New Manager Account</p></figcaption></figure>

Next, set the manager name and email address.

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-25 205707.png" alt=""><figcaption><p>Set the manager name and email address</p></figcaption></figure>

After this, enable the "**Limit manager access**" option.

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-25 205711.png" alt=""><figcaption><p>Enable the "Limit manager access" option</p></figcaption></figure>

Now, select the sections that you want to provide the manager access to.

{% hint style="info" %}
You can also set up read-only permissions for manager accounts.&#x20;
{% endhint %}

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-25 205714.png" alt=""><figcaption><p>Select the sections that you want to provide the manager access to</p></figcaption></figure>

Finally, click on **Submit**.

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-25 20571842.png" alt=""><figcaption><p>Click on Submit</p></figcaption></figure>

The manager account will be created, and the permissions will be assigned to it.

<figure><img src="../../.gitbook/assets/image (3).png" alt=""><figcaption><p>The manager account will be created &#x26; permissions will be set</p></figcaption></figure>

The inaccessible sections set for the manager account will display the "You do not have permission to see this data" alert.

<figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
