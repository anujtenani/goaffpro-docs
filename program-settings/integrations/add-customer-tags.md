# Add Customer Tags

**GoAffPro** provides you with the option to add tags to affiliate customers in Shopify.

To add tags to affiliate customers, go to the **Integrations** section in the **Settings** tab of the GoAffPro admin panel.

<figure><img src="../../.gitbook/assets/image (3927).png" alt=""><figcaption><p>Settings > Integrations</p></figcaption></figure>

Here, go to the Customer tags section.

<figure><img src="../../.gitbook/assets/image (3926).png" alt=""><figcaption><p>Customer tags</p></figcaption></figure>

Now, enable the toggle.

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-13 001517.png" alt=""><figcaption><p>Enable the toggle</p></figcaption></figure>

After this, you can choose the tags that you want to add to an affiliate's customer in Shopify. You can also create new customer tags.&#x20;

{% hint style="info" %}
The customer tags option will only apply to customers that come after the feature is activated. Previous customers will not be tagged.
{% endhint %}

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-13 001523.png" alt=""><figcaption></figcaption></figure>

You also have the option to add tags only for new customers by enabling the "Apply tags only on new customers" option. Additionally, you can set up exclusions for affiliates or groups.

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-13 001528.png" alt=""><figcaption></figcaption></figure>
