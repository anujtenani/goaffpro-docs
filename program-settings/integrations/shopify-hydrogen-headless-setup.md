# Shopify Hydrogen/Headless Setup

**GoAffPro** provides you with the option to add affiliate tracking to your Shopify Hydrogen/ Headless storefront setup.&#x20;

To add affiliate tracking to your Shopify Hydrogen/Headless storefront setup, go to the **Integrations** section in the **Settings** tab of the GoAffPro admin panel.

<figure><img src="../../.gitbook/assets/image (4039).png" alt=""><figcaption><p>Settings > Integrations</p></figcaption></figure>

Here, go to the Hydrogen/Headless setup section.&#x20;

<figure><img src="../../.gitbook/assets/image (4040).png" alt=""><figcaption><p>Hydrogen/Headless setup</p></figcaption></figure>

Now, click on **Setup**.&#x20;

<figure><img src="../../.gitbook/assets/Screenshot 2026-11-25 184614512.png" alt=""><figcaption><p>Click on Setup</p></figcaption></figure>

After this, copy the tracking code and paste it inside the `<head>` tag of the index.html file in your Hydrogen or Headless project. That will integrate it.&#x20;

<figure><img src="../../.gitbook/assets/Screenshot 2026-11-25 184608512.png" alt=""><figcaption></figcaption></figure>
