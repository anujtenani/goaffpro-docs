# Captcha Integration

**GoAffPro** provides you with the option to add captcha verification to the signup page of the affiliate portal.

To add captcha verification to the signup page, go to the **Integrations** section of the **Settings** tab in the GoAffPro admin panel.

<figure><img src="../../.gitbook/assets/image (4032).png" alt=""><figcaption><p>Settings > Integrations</p></figcaption></figure>

Here, go to the Captcha section.

<figure><img src="../../.gitbook/assets/image (4033).png" alt=""><figcaption><p>Captcha</p></figcaption></figure>

Now, select the captcha you want to add to your signup page.

{% hint style="info" %}
The default option adds the Cloudflare Turnstile captcha to the signup page.
{% endhint %}

<figure><img src="../../.gitbook/assets/Screenshot 2026-11-18 135435412.png" alt=""><figcaption><p>Select Captcha</p></figcaption></figure>

After this, the Captcha verification will be added to the signup page of the affiliate portal.
