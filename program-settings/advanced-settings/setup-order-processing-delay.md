# Setup Order Processing Delay

**GoAffPro** provides you with the option to set up the order processing delay for new orders.&#x20;

To set up the order processing delay for new orders, go to the **Advanced** section in the **Settings** tab of the GoAffPro admin panel.

<figure><img src="../../.gitbook/assets/image (4028).png" alt=""><figcaption><p>Settings > Advanced</p></figcaption></figure>

Here, go to the Order processing delay section.&#x20;

<figure><img src="../../.gitbook/assets/image (4029).png" alt=""><figcaption><p>Order processing delay</p></figcaption></figure>

Now, set the delay time.&#x20;

{% hint style="info" %}
Example: If you have set up commission rules that apply to sales with specific order tags in your program, you can set up a processing delay of 5 minutes. This allows the order tag to be applied to the order in your store before it is processed in GoAffPro.
{% endhint %}

<figure><img src="../../.gitbook/assets/Screenshot 2026-11-11 162540.png" alt=""><figcaption><p>Set the delay time</p></figcaption></figure>

You can enable the "Refetch the order data during processing" toggle to ensure that changes to the order, such as order tags or upsells, are included in the initial phase of order processing.

<figure><img src="../../.gitbook/assets/Screenshot 2026-11-11 16254642.png" alt=""><figcaption><p>Enable the "Refetch the order data during processing" option</p></figcaption></figure>

Finally, the order processing delay will set for your program.&#x20;
