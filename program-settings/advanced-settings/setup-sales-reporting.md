# Setup Sales Reporting

**GoAffPro** provides you with the option to set up how sales are reported in the app.

To set up how sales are reported, go to the **Advanced** section of the **Settings** tab in the GoAffPro admin panel.

<figure><img src="../../.gitbook/assets/image (4009).png" alt=""><figcaption><p>Settings > Advanced</p></figcaption></figure>

Here, go to the Sale reporting section.

<figure><img src="../../.gitbook/assets/image (4010).png" alt=""><figcaption><p>Sale reporting</p></figcaption></figure>

Now, choose between order total or commissionable value (order subtotal).

{% hint style="info" %}
The order subtotal refers to the order amount before factoring in shipping and taxes and after accounting for any discounts. The order total is the complete amount, which includes both shipping fees and taxes.

For example, if the order total is $100, with the product price being $90 and the shipping fee $10, then the order subtotal would be $90.&#x20;

In this sale, if a 10% discount is also applied to the product price, the order total would be $91 ($81 for the product price + $10 for shipping). In this case, the order subtotal would be $81.
{% endhint %}

<figure><img src="../../.gitbook/assets/Screenshot 2026-11-03 213301.png" alt=""><figcaption><p>Choose between order total or order subtotal</p></figcaption></figure>

You can also configure volume calculations based on line items, commissionable line items, or commissionable product-qualified volume. Additionally, you can choose the "Calculate Commission on" option to use either default or qualified volume.
