# Show Popup for Select Products

**GoAffPro** provides you with the option to show the post-checkout popup to customers when they purchase select products from the store.&#x20;

To show the post-checkout popup for select products, go to the **Post Checkout Popup** tab in the GoAffPro admin panel.

![Post Checkout Popup](<../../../.gitbook/assets/image (2290).png>)

Here, click on **Select & Customize** in the Advanced popup style section.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-29 203148.png" alt=""><figcaption><p>Advanced Style > Click on Select &#x26; Customize</p></figcaption></figure>

This will open up the Advanced Popup customization section.

<figure><img src="../../../.gitbook/assets/image (3919).png" alt=""><figcaption><p>Advanced Popup </p></figcaption></figure>

Now, click on **Edit** in the Other Configuration section.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-29 203153.png" alt=""><figcaption><p>Other Configuration > Click on Edit</p></figcaption></figure>

After this, select the products for which you want to show the popup.&#x20;

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-29 2034242.png" alt=""><figcaption><p>Select the products</p></figcaption></figure>

Finally, click on **Save**.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-29 203202.png" alt=""><figcaption></figcaption></figure>
